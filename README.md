# Todos pelo Nicolau

Página única, responsiva, em HTML, CSS e JavaScript. Abra `dist/index.html` no navegador. Para servir localmente: `python -m http.server 8080 --directory dist`.

A seleção de pacotes gera números aleatórios sem repetição dentro da combinação. O formulário valida nome e telefone e exibe um resumo que pode ser copiado. Nenhuma informação é enviada ou persistida. Não há reservas, pagamentos, confirmação de disponibilidade ou sorteios reais.

A cesta é uma ilustração SVG: a fotografia referenciada no HTML original não foi fornecida. Substitua `dist/cesta.svg` por uma foto real e ajuste o texto alternativo e a legenda em `dist/index.html` quando a fotografia estiver disponível.

Antes de receber participações reais, integrar disponibilidade, reservas e pagamentos no servidor e inserir os dados e regras confirmados pela organização.
